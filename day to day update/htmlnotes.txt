Anchor tag(linking tag) : 
-------------------------

    -> <a></a> tag used to link external web sites, webpages , documents, javascript alert message ..etc 
    -> <a></a> tag content default color :blue 
    -> active <a></a> tag content color :red 
    ->visited <a></a> tag content color :purple 


    Anchor tag Attributes: 
    -----------------------
        1. href : it will accept url or path as a value
        2. target : it will decide the page will open in new tab or same tab based on the values [_blank , _self , _top , _parent]
        3. download
